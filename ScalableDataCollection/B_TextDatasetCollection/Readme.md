# **Dataset Name: Wikipedia Wood Dataset**

## **Description:**
This dataset contains information about 20 different types of wood, extracted from Wikipedia. Each entry includes the title of the Wikipedia article, content about the wood, and the last known publication date.

## **Wood Types:**
- Oak
- Maple
- Walnut
- Mahogany
- Cherry
- Teak
- Rosewood
- Ash
- Birch
- Hickory
- Pine
- Cedar
- Redwood
- Spruce
- Fir
- Larch
- Ebony
- Bamboo
- Wenge
- Zebrawood

## **Use Case: Wood Classification & Information Retrieval**
### **Objective:**
Develop an NLP-based application to classify wood types based on their descriptions and enable efficient information retrieval.

### **Application Scenario:**
A woodworking company or an online furniture retailer can utilize this dataset to:
- **Automate customer queries**: A chatbot can extract key features from the dataset and answer customer questions about different wood types.
- **Build a recommendation system**: Recommend suitable wood materials based on user preferences and product requirements.
- **Educational Tool**: This dataset can serve as a knowledge base for students and professionals in carpentry, interior design, or forestry studies.

### **Potential Enhancements:**
- Perform sentiment analysis on wood-related reviews and compare characteristics.
- Integrate with a database of wood pricing and availability for market analysis.
- Use Named Entity Recognition (NER) to extract and categorize properties like durability, grain pattern, and water resistance.

## **Dataset Format:**
- **Columns:** `title`, `publication_date`, `content`, `cleaned_content`
- **File Type:** JSON / CSV

This dataset provides a structured way to analyze and utilize textual data for various NLP-based applications!
