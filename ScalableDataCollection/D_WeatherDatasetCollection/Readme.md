# Weather Data Scraping and Analysis Project
=============================================


## Name of the dataset:
#### IndiaWeather20

----------

## Overview
-----------

This project involves scraping and analyzing historical weather data for 20 major cities in India using the Visual Crossing Weather API.

## Cities
--------

- **Mumbai**
- **Delhi**
- **Bengaluru**
- **Hyderabad**
- **Ahmedabad**
- **Chennai**
- **Kolkata**
- **Surat**
- **Pune**
- **Jaipur**
- **Lucknow**
- **Nagpur**
- **Indore**
- **Patna**
- **Bhopal**
- **Coimbatore**
- **Vadodara**
- **Visakhapatnam**
- **Kanpur**
- **Ludhiana**

## Features
---------

- **datetime**
- **temp** (current temperature)
- **tempmax** (maximum temperature)
- **tempmin** (minimum temperature)
- **humidity**
- **precip** (precipitation amount)
- **precipprob** (precipitation probability)
- **windspeed**
- **conditions**

## Plots
------

- **Histograms**: Temperature, Humidity, Precipitation distributions.
- **Scatter Plot**: Temperature vs. Humidity.
- **Bar Chart**: Average Precipitation Probability by City.
- **Time Series Plot**: Temperature over time for each city.
- **Box Plot**: Wind Speed distribution across cities.
